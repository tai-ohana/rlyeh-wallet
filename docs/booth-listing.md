# BOOTH 出品プラン — R'lyeh Wallet（0円配布）

目的：販売ではなく **BOOTHに載せて知名度を上げる**こと。価格は 0 円。

---

## 0. 最重要：ガイドライン上の注意

BOOTHは「**誘導・告知を主目的とする商品**」を禁止商品に追加している（実物の頒布を伴わず、外部サイトへの誘導・告知だけをする出品は非公開化の対象）。

→ **「R'lyeh Wallet の宣伝ページ」だけを出すのはNG**。
→ **それ単体で使える実物（ダウンロード素材）を0円で配布し、その中や説明文で R'lyeh Wallet を紹介する**形にする。

出品前に BOOTH 公式ガイドライン（禁止商品の項目）を必ず本人が読んで確認すること。

## 1. 配布物（ダウンロード商品の中身）案

CoC プレイヤーがそれ単体でも欲しくなるものを作る。おすすめ順：

| # | 配布物 | 中身 | Walletとのつながり |

同梱する `はじめにお読みください.txt`（または PDF の最終ページ）に R'lyeh Wallet の紹介と URL を書く。

- ショップ名：`R'lyeh Wallet` （または `ルルイエウォレット`）
- ショップアイコン：`public/logo.png`
- ショップ説明：
  `クトゥルフ神話TRPGのセッション記録サービス「R'lyeh Wallet」公式ショップ。TRPGで使える記録用テンプレートや素材を配布しています。 https://rlyehwallet.com`
- pixiv アカウント連携 → ショップのリンク欄に X / サイトURL を登録

---

## 5. 知名度を上げるための導線

1. **公開時に X で告知**：「#CoC #クトゥルフ神話TRPG #TRPG素材 無料配布」＋ サムネ画像
2. **アプリ内から BOOTH へ**：設定画面やフッターに「通過記録テンプレート配布中（BOOTH）」リンク（逆方向の導線）
3. **定期的に素材を追加**：新商品が出るたびにショップがフォロワーに通知される。月1で小さな素材を足すのが効果的
4. **「スキ」数を伸ばす**：0円商品はスキが付きやすく、スキ数がランキング・おすすめ表示に効く
5. **即売会（TRPGフェス等）でも同じ素材を配布** → QRでBOOTH/サイトへ
