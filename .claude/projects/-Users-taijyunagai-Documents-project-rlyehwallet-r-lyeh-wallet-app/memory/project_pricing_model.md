買い切り型モデルに確定（2026-04-11 決定）。

**Why:** シンプルな収益モデルに集中。サブスクリプションの複雑さを排除。

**How to apply:**
- 料金ページはウォレット購入（¥980 ローンチ割引、定価¥1480）のみ表示
- サポーター・配信者プランは `suspended: true` のまま保持（将来変更の可能性あり）
- マッチング機能（シナリオ希望/KP募集）はコード上は残すが、UIに表示しない
- ソーシャル機能（フォロー・フレンド等）は訴求せず、機能は残す
- 新機能追加時に「これはサブスクかどうか」と考えない — 全て買い切りスコープで考える
